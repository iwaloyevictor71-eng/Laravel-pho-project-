# Simple Expense Tracker

## Project Description
A simple expense tracker built with PHP. It helps users manage and monitor their daily expenses.

## Features
- Add new expenses
- Edit existing expenses
- Delete expenses
- Categorize expenses
- Calculate total expenses
- Store expense records using JSON file storage

## Technologies Used
- PHP
- JSON
- HTML

## Project Structure
- `index.php` – Main project file
- `functions.php` – Contains PHP functions
- `expenses.json` – Stores expense records
- `README.md` – Project documentation
