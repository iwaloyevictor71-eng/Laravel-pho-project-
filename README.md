# PHP Utility Library

A collection of reusable PHP utility functions built as a Week 3 project assignment.

## Functions

1. `calculateTax()` - Calculates tax on an amount.
2. `formatCurrency()` - Formats a number as currency.
3. `generateSlug()` - Converts text into a URL-friendly slug.
4. `calculateAge()` - Calculates age from a date of birth.
5. `validateEmail()` - Validates email address syntax.
6. `paginate()` - Splits an array into pages.
7. `generateReference()` - Generates a reference code.

## Requirements

- PHP 8.0 or later recommended.

## How to run

1. Make sure PHP is installed.
2. Open a terminal in this project folder.
3. Run:

   ```bash
   php index.php
   ```

## Project files

- `utility.php`: Contains the reusable functions.
- `index.php`: Demonstrates and tests the functions.
- `README.md`: Project documentation.
